# 🐱 Router Resources Demo

A web application developed in **Angular 22** that generates custom cat images with personalized messages using the public API [CATAAS (Cat as a Service)](https://cataas.com/).

The project demonstrates the use of the new Angular API **Router Resources**.
---

## 🚀 Technologies 

- **Angular 22**

---

## 🛠️ Prerequisites

Make sure you have installed on your machine:

- **Node.js**: `v20.x` or higher
- **Angular CLI**: `v22.2` or higher (`npm install -g @angular/cli`)
